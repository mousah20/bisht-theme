# بشت — ثيم سلة

متجر بشوت يقيس قبل ان يعرض.

## ما يميزه بنيويا

- **غلاف كامل الشاشة** يدخل منه الزائر بستارة قماش مقطعة على سبع ثنيات، تُسدل اثناء التحميل الفعلي فتغطي زمنه.
- **عمود منتجات** بطول الشاشة بدل شبكة بطاقات.
- **حاسبة قياس** بالطول والكتف: القامة والبنية والاستعمال ⇒ مقاس واحد. القاعدة من الخياطين: طول البشت = القامة ناقص ١٢–١٦ سم.
- **طبقة جوال مصممة** لا مضغوطة: شرفة شراء سفلى بـ`safe-area`، درج قوائم، و`pointer:coarse` يرفع كل هدف لمس الى ٤٤ بكسل.
- **بلا وراثة من رائد**: SCSS من الصفر، وتايلوند لمكونات سلة وحدها. `public/` ٦٠ كيلوبايت مقابل ١.١ ميجابايت.

## البناء

```
pnpm install
pnpm run production   # او watch للتطوير
```

## البنية

```
src/assets/styles/   نظام التصميم: رموز، اساس، تخطيط، عناصر، ثم blocks لكل قسم
src/assets/js/       وحدات صغيرة: ستارة، درج، شرفة، كشف، محرك القياس
src/views/layouts/   master و customer
src/views/pages/     الصفحات كما يسميها Twilight
src/views/components/ الرأس والفوتر والمكونات المخصصة تحت home/
```
